Kod skener

Slikaj kartice, a kodovi se sami pročitaju i upišu u tvoj digitalni album. Bez kucanja, bez grešaka.

01

Anthropic API ključ

  1. Napravi nalog na console.anthropic.com i dopuni kredit. Dovoljno je par dolara.
  2. Napravi API ključ (počinje sa sk-ant-).
  3. Preporuka: postavi mesečni limit potrošnje u konzoli.

Jedna slika košta delić centa. Ključ se čuva samo u tvom browseru i šalje se samo Anthropic-u.

02

Dodaj dugme u bookmarke

Računar

Prevuci ovo dugme na traku sa bookmarkima:

📷 Kod skener

Android · Chrome
  1. Kopiraj ovaj tekst:
  1. Sačuvaj bilo koju stranicu kao bookmark, pa ga izmeni: ime kodskener, a umesto adrese nalepi kopirani tekst.
  2. Na stranici albuma ukucaj kodskener u adresnu traku i dodirni bookmark iz predloga.
03

Koristi ga

  1. Uloguj se na digitalni-album.igraoni.ca (bilo koja stranica albuma).
  2. Klikni bookmark. Prvi put unesi API ključ (⚙️).
  3. 📷 Slikaj kartice (telefon) ili 🎥 Kamera → 📸 Snimi (laptop).
  4. Proveri kodove (crveno = nečitko), pa Pošalji sve. ✅ = upisan, ❌ = sajt ga ne prihvata.

Nezvaničan alat, nije povezan sa Krašom. Šalje samo kodove sa kartica koje slikaš, istim putem kao kad ih ručno upišeš. Ako sajt promeni način rada, alat može prestati da radi.
